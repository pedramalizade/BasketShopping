

# BasketShopping - E-Commerce Basket Management System

BasketShopping is a backend-focused e-commerce basket management system built with **.NET 9.0** and Clean Architecture principles.

It simulates real-world shopping cart workflows including product selection, basket management, and user-based operations.

---

## 🚀 Overview

This system provides a scalable and modular backend for managing user shopping baskets in an e-commerce environment.

It is designed to reflect production-level backend design patterns.

---

## 🏗️ Architecture

The project is built using **Clean Architecture**:

- Domain Layer: Business rules and entities
- Application Layer: Business workflows and use cases
- Infrastructure Layer: Data persistence and external integrations
- API Layer: RESTful endpoints

---

## ✨ Key Features

- 🛒 **Basket Management**
  - Add/remove items
  - Update quantities
  - Calculate totals

- 👤 **User-Based Basket System**
  - Each user has an isolated basket

- 🔐 **Secure API**
  - JWT-based authentication

- 🗄️ **Database Integration**
  - EF Core for persistence

- ⚡ **Scalable Design**
  - Designed for extension into full e-commerce system
---
## 🧠 Design Concepts

- Clean Architecture
- SOLID Principles
- Domain-driven design principles (light usage)
- Separation of concerns

---

## 🛠 Tech Stack

- ASP.NET Core (.NET 9)
- Entity Framework Core
- SQL Server
- JWT Authentication

## 📌 Purpose

This project demonstrates how to build a scalable basket management system as part of a modern e-commerce backend.
